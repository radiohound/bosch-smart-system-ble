# Images

Photos and screenshots linked from the docs in the parent `docs/` folder.

Reference one from a page with a relative link. For example, from `docs/NAV-PROTOCOL.md`:

```markdown
![Kiox 300 rendering a two-line alert with a warning icon](images/kiox-alert.jpg)
```

Keep filenames short, lowercase, and descriptive (e.g. `kiox-alert-warning.jpg`, `kiox-menu-optiongroup.jpg`).

> **Before adding a photo:** this repository is public — scrub any Bosch serial numbers,
> personal information, or anything else that shouldn't be shared. Prefer downscaled JPG/PNG
> to keep the repo light.
